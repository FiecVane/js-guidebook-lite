### 本地开发

环境要求

- [Node.js](https://nodejs.org) 22.0 或更高版本
- [pnpm](https://pnpm.io) 包管理器（推荐）
- [git](https://git-scm.com) 分布式版本控制系统

```bash
# 克隆仓库
git clone https://github.com/FiecVane/js-guidebook-lite.git

# 进入目录并安装依赖
cd js-guidebook-lite
pnpm i

# 启动开发服务器
pnpm dev

# 构建生产版本
pnpm build

# 预览生产构建
pnpm preview
```
